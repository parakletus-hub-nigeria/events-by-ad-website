
# Events by AD — The Event Business Blueprint

Static landing page for **The Event Business Blueprint**, a two-day live virtual business training for event professionals by Events by AD.

## Local preview

Open `index.html` in a browser, or serve this directory with a static web server.

## Included pages

- `index.html` — event landing page
- `terms.html` — terms of participation
- `privacy.html` — privacy notice
- `robots.txt` and `llms.txt` — crawl and AI-reader guidance

Before launch, replace the clearly highlighted legal-business and refund-policy placeholders in the Terms and Privacy pages, then set the canonical, social-preview and structured-data URLs to the production domain.
